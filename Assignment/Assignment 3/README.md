# Assignment 3 — Predicting Car Price as Four Classes

Student ID: **126671**. The notebook adapts the course's multinomial logistic regression class and the A2 preprocessing to classify car prices into quartiles 0–3.

## Files

- `A3_Predicting_Car_Price_126671.ipynb`: documented work and manual versus scikit-learn classification report.
- `model.py`: A2-aligned cleaning, training-only preprocessing, softmax regression, optional ridge, and classification metrics.
- `train.py`: baseline/ridge experiments, model selection on validation data, held-out test evaluation, local model save, optional remote MLflow logging.
- `app/app.py`, `app/Dockerfile`: Dash category predictor and Docker image, adapted from the A1 form.
- `tests/test_model.py`: two required model unit tests.
- `Cars.csv`: source dataset reused from A2. `app/model.pkl` and `experiment_results.json` are generated by training.
- Repository-root `.github/workflows/a3.yml`: tests on push; deployment after passing tests when enabled.

## Run locally

From this folder:

```bash
python -m pip install -r requirements.txt
python train.py
python -m pytest -q tests
python app/app.py
```

Open http://localhost:8050. The app predicts a category and shows the quartile price interval in the dataset's original currency units. Blank inputs use A2-style training medians or most frequent brand.

To run the notebook, start Jupyter from this directory so `Cars.csv` and `model.py` resolve. The class boundaries, brand encoder and scaler are learned from the training set. A 20% stratified part of that training set selects ridge strength by validation macro F1. The 30% test set is evaluated once after selection. Support is the number of true examples of a class. Precision, recall and F1 for an undefined denominator use zero, as in scikit-learn with `zero_division=0`.

## MLflow and registry

On an AIT connection, install `mlflow` in addition to the requirements and run:

```bash
python -m pip install mlflow
python train.py --tracking-uri http://mlflow.ml.brain.cs.ait.ac.th/
```

This logs the runs and model artifacts under `126671-a3`, without uploading `Cars.csv`. In the MLflow UI, choose the `selected-final-model` run, register its model artifact as `126671-a3-model`, and set the version to **Staging**. Confirm the exact version and record the link after the server is reachable. The bundled Dash app loads the saved local model; the registered MLflow model is available separately in the course registry.
